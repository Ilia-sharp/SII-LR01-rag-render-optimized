# RAG-Demo.exe — автономная демонстрация

Единственный файл, который можно принести на флешке, запустить на чужом компьютере и показать работу сервиса. **Не нужны** Python, интернет, установка и права администратора: модель и индекс лежат внутри exe.

При запуске открывается браузер с интерфейсом, а в чёрном окне консоли идут логи — те самые `q_hash`, `chunks_found`, `latency_ms`. На защите это удобно: видно и результат, и телеметрию.

---

## Сборка (один раз, ~15 минут)

Нужен компьютер с Windows, Python 3.10+ и интернетом.

1. Скачайте/скопируйте папку проекта.
2. Двойной клик по `desktop\build_exe.bat`.
3. Дождитесь строки `ГОТОВО: dist\RAG-Demo.exe`.

Батник сам создаёт отдельное окружение `.venv-build`, ставит PyTorch (CPU), экспортирует энкодер в ONNX, квантует его в int8, строит индекс по `data/` и упаковывает всё в exe. Основной проект и ваше системное окружение он не трогает.

На macOS или Linux используйте `bash desktop/build_exe.sh` — получится бинарник для этой же ОС. PyInstaller не умеет собирать под чужую систему: exe для Windows собирается только на Windows.

Ручной запуск тех же шагов, если хочется контроля:

```bat
python -m venv .venv-build && .venv-build\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r desktop\requirements-build.txt
python desktop\prepare_bundle.py          --no-quantize  (опционально: fp32, точнее и тяжелее)
pyinstaller --noconfirm --clean desktop\rag_demo.spec
```

**Размер.** С квантизацией int8 exe получается примерно 150–200 МБ, без неё — около 500 МБ. Первый старт из одного файла занимает 5–15 секунд: Windows распаковывает содержимое во временную папку. Если хочется мгновенного старта, откройте `desktop/rag_demo.spec`, поставьте `ONEFILE = False` и пересоберите — получится папка `dist/RAG-Demo/` с быстрым exe внутри (её носят целиком).

## Сценарий показа (3 минуты)

1. Запустите `RAG-Demo.exe`, дождитесь открытия браузера. Скажите, что интернета нет и всё считается локально.
2. Нажмите готовый пример про отпуск. Покажите ответ и блок «Источники»: имя файла, номер фрагмента, косинусная схожесть.
3. Нажмите «Показать ответ API (JSON)» — это ровно тот контракт, который требует задание: `answer`, `sources`, `model_version`.
4. Нажмите пример про борщ из марсианской свёклы. Сервис отвечает «Не нашёл информации по вашему вопросу», источников нет.
5. Переключитесь на окно консоли: видно строку `ask q_hash=... q_len=... chunks_found=... latency_ms=...` — логируются метрики, а не текст вопроса.
6. Если спросят про «настоящий» сервис: `uvicorn app.main:app` и `curl` по `/ask` из основного README.

## Что внутри и чем отличается от серверной версии

| | Серверная версия (сдаётся) | RAG-Demo.exe |
| --- | --- | --- |
| Транспорт | FastAPI + uvicorn | `http.server` из стандартной библиотеки |
| Векторное хранилище | ChromaDB | numpy-массив, полный перебор |
| Энкодер | sentence-transformers (PyTorch) | тот же энкодер, экспортированный в ONNX |
| Нарезка и сборка ответа | `app/chunker.py`, `app/rag.py` | **те же модули** |

Нарезка, фильтрация по порогу, лексическая проверка и экстрактивная сборка ответа — общий код, поэтому exe отвечает так же, как сервис. Заменены только транспорт и способ хранения векторов: ChromaDB и PyTorch плохо упаковываются в один файл и весят гигабайты, а на 18 чанках полный перебор по numpy занимает микросекунды.

Файлы:

- `prepare_bundle.py` — экспорт модели в ONNX, квантизация, построение индекса, контрольные запросы перед упаковкой
- `onnx_encoder.py` — токенизация, инференс, mean pooling, L2-нормализация; используется и при сборке индекса, и в exe
- `demo_app.py` — локальный сервер, `/ask`, `/health`, логирование, автозапуск браузера
- интерфейс берётся из `app/ui.html` — он общий с серверной версией
- `rag_demo.spec` — конфигурация PyInstaller

## Если что-то пошло не так

**«Windows защитила ваш компьютер» (SmartScreen).** Файл не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае». Подпись стоит денег и для учебного проекта не нужна.

**Антивирус ругается на exe.** Обычная ложная тревога на файлы PyInstaller. Добавьте в исключения либо соберите вариант `ONEFILE = False` — папку антивирусы трогают реже.

**Браузер не открылся.** Адрес напечатан в консоли, обычно `http://127.0.0.1:8765` — откройте вручную.

**Ошибка при `pip install torch`.** Уберите `--index-url` и поставьте обычный `pip install torch` — будет дольше качаться, но сработает.

**Экспорт через optimum упал.** Скрипт автоматически переключается на прямой `torch.onnx.export`. Если упало и это, соберите fp32-вариант: `python desktop\prepare_bundle.py --no-quantize`.

**Изменили документы в `data/`.** Пересоберите: `python desktop\prepare_bundle.py`, затем `pyinstaller --noconfirm desktop\rag_demo.spec`. Индекс внутри exe не обновляется сам.
